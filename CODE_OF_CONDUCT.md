# Davranış kuralları

Bu proje [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) ilkelerini benimser.

Kısaca:
- Herkese saygılı ve yapıcı davran. Taciz, ayrımcılık ve kişisel saldırılara yer yok.
- Eleştiriyi koda yap, kişiye değil. Farklı deneyim seviyelerine sabırlı ol.
- Uygunsuz davranış gören, repo sahibine GitHub üzerinden (issue'da etiketleyerek veya profil sayfasındaki iletişim yoluyla) bildirebilir.

Bakımcılar bu kurallara uymayan yorum, commit ve issue'ları kaldırabilir veya katılımcıyı projeden uzaklaştırabilir.
